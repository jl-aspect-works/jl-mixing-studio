# JL Mixing Studio v1.1.1 / Automation v1.5 Coordinated Acceptance

## Purpose

This document is the acceptance source of truth for the refreshed JL Mixing Studio v1.1.x release that incorporates the Windows and Automation v1.5 compatibility fixes merged after Studio v1.1.0.

Target candidate:

- JL Mixing Studio `v1.1.1-rc.1`
- JL Mixing Automation `v1.5.0-rc.2`
- Automation API `1.0`
- Workspace metadata schema `1.1.0`

Studio and Automation retain independent product versions. Compatibility is determined by Automation API version/capabilities and supported metadata schemas, not matching product release numbers.

## Release gate

The candidate is releasable only when all applicable checks below have a recorded result and no release-blocking defect remains.

### Automated validation

- [ ] Studio `npm run release:verify -- v1.1.1-rc.1`
- [ ] Studio `npm run check`
- [ ] Studio GitHub CI passes on the RC-prep commit
- [ ] Automation v1.5.0-rc.2 release artifacts are available and validated
- [ ] Studio release workflow produces Intel macOS, Apple Silicon macOS, and Windows x64 installers
- [ ] Release checksums are generated and verified
